# QQ Pet Replica Progress

Current branch: `codex/native-qq-penguin`

This project is still in an early reconstruction stage. The current build is not a 1:1 QQ Pet recreation yet. It is a native desktop-pet foundation that proves the Windows 10/11 `.exe` shell can host the existing penguin SWF resources directly on the desktop.

## What Is Already Done

| Area | Status | Notes |
| --- | --- | --- |
| Native Windows desktop pet shell | Done | Transparent, borderless, always-on-top, hidden from the taskbar. |
| `.exe` packaging | Done | Portable exe is generated by `npm run build:exe`. |
| Tray menu | Done | Can show, hide, and quit the pet. |
| Direct SWF playback | Partial | Ruffle loads files from `Penguin/GG`. |
| Local save | Partial | Position and basic pet stats are saved locally. |
| Basic interaction | Prototype | Dragging, right-click menu, double-click status, short random walking. |
| Action viewer | Done | `npm run view:actions` opens a tool to inspect every SWF action. |

## What Is Not 1:1 Yet

| Area | Current Problem | Required Direction |
| --- | --- | --- |
| Startup presentation | Current pet says prototype text like "我来啦。" | Replace with original-style startup behavior, or remove text until exact original copy is known. |
| Action bubbles | Current actions show invented text | Remove invented action bubbles; only show bubbles that match original QQ Pet behavior/copy. |
| Animation switching | Ruffle reloads SWF files and causes visible flicker | Build a better action player: preload hidden players, swap visibility, or convert SWF frames to sprite/video assets. |
| Action mapping | Many actions are guessed by file names | Use the action viewer to verify every SWF visually and map it to original behavior. |
| Original UI | Menu/status text is modern placeholder UI | Recreate original QQ Pet menus, status panels, icons, and wording. |
| Pet logic | Stats are simplified | Rebuild original-like hunger, cleanliness, mood, health, growth, level, yuanbao, food/items, study/work/sick rules. |
| Mini games | Not restored | Fishing exists in the repo, but not integrated into the desktop pet flow. |
| Original desktop behavior | Only basic drag/walk exists | Need original idle schedule, movement bounds, drag/drop behavior, click reactions, random events, and notifications. |

## Current Restoration Level

Rough estimate:

- Desktop-pet shell: 45%
- Windows `.exe` packaging: 80%
- SWF resource inventory: 35%
- Correct original action mapping: 15%
- Original QQ Pet UI: 5%
- Original pet state/gameplay rules: 10%
- Overall 1:1 restoration: about 15%

## Immediate Fixes Before Adding More Features

1. Remove all invented bubble lines from normal actions.
2. Keep bubbles only for explicit status/debug until original copy is confirmed.
3. Use the action viewer to label every SWF with the real visual behavior.
4. Fix flicker by replacing single-player reloads with a preloaded-player action layer.
5. Build the original-style right-click/menu/status surface after action mapping is reliable.
