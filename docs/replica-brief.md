# QQ 企鹅一比一复刻目标

本分支目标不是复刻一个能打开 QQ 宠物网页的窗口，而是复刻原版 QQ 宠物企鹅作为 Windows 桌面虚拟宠物的体验。

## 产品形态

原版 QQ 宠物是桌面虚拟宠物。企鹅应该直接出现在 Windows 桌面上，而不是嵌在一个模拟 XP 桌面、浏览器页或普通应用窗口里。

当前分支的第一版实现：

- 透明背景
- 无边框
- 置顶
- 不显示任务栏按钮
- 托盘菜单可隐藏、显示、退出
- 直接加载 `Penguin/GG` 下的企鹅 SWF 动作

## 需要复刻的核心体验

- 企鹅直接站在桌面上
- 可拖拽移动
- 空闲、走路、被拎起、落地、互动等动作
- 气泡对白和状态提醒
- 喂食、清洁、逗宠
- 饥饿、清洁、心情、成长、健康等状态
- 元宝、物品、食品、日用品
- 学习、打工、看病、小游戏
- 本地存档，不依赖旧 QQ 服务器
